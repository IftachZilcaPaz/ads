# 📸 BP Social — לוח פרסום לאינסטגרם

תכנון, אישור ותזמון פוסטים לאינסטגרם, עם עוזר AI שכותב קפשנים לפי המותג, הקמפיין והמוצר.

- **אפליקציה ב-Netlify**: לוח קנבן, יומן חודשי, סטודיו להעלאת תמונות וכתיבת קפשן, ניהול קמפיינים ומוצרים וקול המותג.
- **n8n**: מפרסם בזמן, שולח בקשות אישור בטלגרם, מקבל תמונות מהבוט והופך אותן לטיוטות עם קפשן, ושולח בדיקה לילית.
- **Postgres (Railway)**: מקור האמת. הפעולות הרגישות (נעילה לפרסום, אישור מטלגרם) הן פונקציות SQL אטומיות. הגיליון הישן מועבר פעם אחת עם `npm run db:import-sheet`.

## הכלל החשוב: שום דבר לא עולה בלי אישור

| עמודה בלוח | מה זה אומר | יעלה? |
|---|---|---|
| **טיוטות** | עבודה בתהליך | ❌ אף פעם |
| **ממתין לאישור שלי** | מוכן ומתוזמן, מחכה לך | ❌ לא בלי אישור. n8n שולח לך בקשה בטלגרם 12 שעות לפני המועד |
| **מאושר ומתוזמן** | אישרת | ✅ עולה אוטומטית במועד |
| **פורסם** / **נכשל-נדחה** | היסטוריה, או משהו שדורש טיפול | — |

- מאשרים בלוח (כפתור, גרירה או "אשר הכל") או בכפתור בטלגרם.
- **אישור הוא על תוכן מסוים**: שינוי בקפשן, במדיה או בסוג מבטל את האישור. הזזת מועד לא מבטלת.
- כפתור טלגרם ישן (אחרי עריכה, או כזה שכבר טופל) לא יעבוד. לחיצה כפולה לא תפרסם פעמיים.
- "אישור קבוע" בפוסט = לפרסם בזמן בלי בקשה נפרדת. מיועד לתוכן שגרתי בלבד.

## ✨ עוזר הקפשנים

בסטודיו (או בעריכת כל פוסט): מעלים תמונה או וידאו, בוחרים קמפיין ו/או מוצר, כותבים בריף קצר אם רוצים, ו-Claude מחזיר 3 גרסאות בזוויות שונות. אפשר לבחור אחת, לערוך, או לשכתב בלחיצה ("קצר יותר", "יותר מכירתי"...).

Claude מקבל: את התמונה, את **קול המותג** (לשונית "מותג"), את פרטי **הקמפיין** (מטרה, מסר, הצעה, CTA, האשטגים), את פרטי **המוצר**, ועד 4 קפשנים שפורסמו כדי לחקות את הסגנון. הוא לא ימציא מחירים או מבצעים שלא כתובים בהקשר, ולא ישתמש במקף ארוך.

**מטלגרם**: שולחים לבוט תמונה או וידאו, והוא שואל כמה שאלות עם כפתורים:

1. 📐 פוסט או סטורי? (לווידאו: ריל או סטורי). סטורי מדלג ישר לשאלת המועד, כי לסטורי אין קפשן באינסטגרם
2. 📣 לאיזה קמפיין? · 🏷 איזה מוצר? (רק פעילים; אפשר "בלי")
3. ✍️ מה חשוב להגיד? (משפט חופשי, או "תפתיע אותי")
4. ✨ 3 גרסאות לבחירה, או "גרסאות אחרות" / "אכתוב בעצמי"
5. 🗓 מתי? (היום/מחר בשעות מוצעות, "עכשיו", או מועד בטקסט: `19:30`, `מחר 09:00`, `5.10 19:30`)
6. תצוגה מקדימה ← ✅ אשר ותזמן / שנה מועד / שנה קפשן / השאר כטיוטה

קיצורים בטקסט של התמונה: `#winter #kitchen` מדלג על השאלות האלה, שאר הטקסט הוא הבריף, ו-`!הקפשן שלי` נשמר כמו שהוא בלי AI. "ביטול" עוצר את השיחה (הטיוטה נשארת בלוח). השיחה רצה באפליקציה (`/api/bot`); n8n רק מעביר אליה את ההודעות ומבצע את קריאת ה-AI.

## 📣 דף קמפיין

לוחצים על קמפיין ב"קמפיינים ומוצרים":

- **📋 בלוח**: כמה פוסטים של הקמפיין בכל עמודה.
- **📈 אורגני**: חשיפה, צפיות, לייקים, תגובות, שמירות ושיתופים לכל פוסט שפורסם (Instagram Insights, נשמר במטמון ל-3 שעות; 🔄 מרענן).
- **💰 ממומן**: הוצאה, חשיפות, קליקים, CTR, עלות לקליק ותוצאות, לקמפיין המקושר ב-Meta (מטמון לשעה).
- **✨ בניית קמפיין עם AI**: Claude מקבל את פרטי הקמפיין, המוצרים, קול המותג והפוסטים הקיימים, ומחזיר:
  - **תוכנית תוכן**: פוסטים עם תאריך, שעה, סוג, קפשן ומה לצלם. מסמנים ← "צור בטיוטות", והם מופיעים בלוח בלי מדיה; מוסיפים תמונה ומאשרים כרגיל.
  - **תוכנית מודעות**: מטרה, תקציב יומי, קהל, 2-3 טקסטים למודעה, טיפים ויעדים. "שמור" ← "צור ב-Meta" יוצר קמפיין (וכשאפשר גם קבוצת מודעות) **במצב מושהה**: שום כסף לא יוצא עד שמפעילים ב-Ads Manager. המודעות עצמן (תמונה+טקסט) נוספות שם.
- קמפיינים שכבר קיימים ב-Meta: **⬇ ייבוא מ-Meta** בלשונית הקמפיינים מציג את כל הקמפיינים בחשבון המודעות (`meta_ad_account_id`), ויוצר את המסומנים כבר מקושרים, עם התאריכים והסטטוס שלהם. אפשר גם להדביק מזהה ידנית ב"עריכה".

## 📊 ניתוחים

`#/analytics` מציג את חשבון האינסטגרם כולו (לא רק פוסטים שעלו דרך המערכת), ל-7 או 30 הימים האחרונים:

- **סיכום**: חשיפה, צפיות, אינטראקציות (לייקים, תגובות), שמירות ושיתופים, ושיעור מעורבות ממוצע (אינטראקציות חלקי חשיפה).
- **חשיפה יומית**: גרף, עם ריחוף או חצים על המקלדת לכל יום.
- **מה עובד**: מעורבות ממוצעת לפי פורמט (ריל, קרוסלה, פוסט), לפי יום בשבוע ולפי שעה (שעון ישראל). "הכי טוב" מסומן רק כשיש לפחות 2 פוסטים בקבוצה.
- **כל הפוסטים**: חשיפה, צפיות, לייקים, תגובות, שמירות, שיתופים ומעורבות, עם מיון לפי כל עמודה וקישור לאינסטגרם. פוסט שעלה דרך המערכת מציג גם את הקמפיין שלו.
- **✨ ניתוח עם AI**: Claude קורא את המספרים והקפשנים ומחזיר ממצאים והמלצות לשבועות הקרובים.

הנתונים נשמרים לשעה (🔄 מושך מחדש מ-Meta). צריך את ההרשאה `instagram_manage_insights`.

## ⚙️ הגדרות: חיבורים והרשאות

`#/settings` מציג מה מחובר עכשיו: האפליקציה של Meta, תוקף הטוקן, ✅/❌ לכל הרשאה, חשבון האינסטגרם וחשבון המודעות, וגם טלגרם, Cloudinary, Claude וכתובת האפליקציה.

- **התחברות עם פייסבוק**: מבקש את כל ההרשאות, מחליף לטוקן של 60 יום ושומר. צריך פעם אחת להוסיף את כתובת ה-callback שמוצגת בדף ל-Valid OAuth Redirect URIs באפליקציה. באפליקציה עם Facebook Login for Business ממלאים גם Configuration ID.
- **הדבקת טוקן**: אותו דבר עם טוקן מ-Graph API Explorer.
- **בחירת חשבונות**: רשימות של חשבונות האינסטגרם וחשבונות המודעות שהטוקן רואה.
- טוקן חדש בלי הרשאות פרסום לא נשמר, והחיבור הקיים נשאר.

        ┌──────────── Netlify ─────────────┐
 דפדפן ─┤  SPA (Preact, RTL)                │

        │  /api/captions Edge function ────┼──▶ Claude API           Watchdog, Token Refresh)

| תיקייה | מה יש בה |
|---|---|
| `src/shared/` | לוגיקת הדומיין המשותפת לשרת ולדפדפן: מחזור חיים של פוסט, אישורים, ולידציה של אינסטגרם, בניית הפרומפט |
| `src/server/` | ה-Store מעל Postgres (נעילת שורות), סשן, ראוטר, שירות הקפשנים, ייבוא הגיליון |
| `db/migrations/` | הסכמה ופונקציות ה-SQL ש-n8n קורא להן (`claim_due_posts`, `request_approvals`, `decide_approval`...) |
| `src/web/` | האפליקציה (Preact + Vite) |

| `n8n/code/` | הקוד של כל Code node, כקבצי JS רגילים עם טסטים |
| `n8n/src/` | הגדרות ה-workflows; `npm run n8n:build` מייצר JSON לייבוא |

## התקנה

המדריך המלא, צעד אחר צעד: **[docs/setup.md](docs/setup.md)**. בקצרה:

1. **Railway**: שירות PostgreSQL (אזור EU West). את `DATABASE_PUBLIC_URL` מעתיקים ל-`.env` בשם `DATABASE_URL`.
2. **מסד הנתונים**: `npm run db:import-sheet` יוצר את הסכמה ומעתיק את הגיליון, פעם אחת.
3. **Netlify**: Import from GitHub, ומשתני סביבה לפי [`.env.example`](.env.example): `APP_PASSWORD`, `SESSION_SECRET`, `DATABASE_URL`, `ANTHROPIC_API_KEY`, `API_TOKEN`.
4. **n8n**: credential מסוג Postgres, ואז `npm run n8n:deploy`. הפקודה מעדכנת ומפעילה את כל ה-workflows דרך ה-API.

## פיתוח

```bash
npm install
npm run dev       # הכול בפקודה אחת: http://localhost:5199 (סיסמה: dev). Postgres מקומי בזיכרון (PGlite) עם נתוני דוגמה
npm run check     # typecheck + טסטים + build
npm run db:migrate  # מעדכן את הסכמה ב-DATABASE_URL
npm run doctor    # למה פוסט לא עלה: מצב הפוסטים, הגדרות חסרות, ריצות ושגיאות אחרונות ב-n8n
TEST_DATABASE_URL=postgresql://... npx vitest run --no-file-parallelism  # הטסטים מול Postgres אמיתי
npm run n8n:build # מייצר את ה-workflows מ-n8n/src
npm run n8n:deploy -- --dry-run  # מה יתעדכן ב-n8n
```

## אבטחה

- הריפו **ציבורי**: אין בו סודות. מזהה ה-credential ו-chat id מוזרקים רק ל-`n8n/dist/` (ב-gitignore) או ישר ל-n8n.
- ה-token של Meta נמצא בטבלת `settings`, והאפליקציה לא מחזירה אותו לדפדפן: היא חושפת רק `cloudinary_cloud` ו-`cloudinary_preset`.
- כניסה בסיסמה, עם cookie מסוג HttpOnly/Secure חתום ב-HMAC. יש בדיקת Origin לכתיבות, השהייה אחרי ניסיונות כושלים, ו-CSP קשוח.
- כל ה-SQL עם פרמטרים, בלי שרשור מחרוזות, כולל ב-n8n. ה-DB אוכף ערכים חוקיים עם CHECK constraints.
- הבוט בטלגרם מגיב רק ל-`telegram_chat_id` שבהגדרות.
