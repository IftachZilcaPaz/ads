‫מודול 4 · Use cases ← Customize ← Embedded Signup Builder‬

הכל מופיע ב-Embedded Signup Builder בדשבורד, עם קוד מוכן להעתקה. הדרך הפשוטה: הקישור Meta-hosted, שמים אותו ככפתור באתר ולא צריך JavaScript. הדרך המלאה: JavaScript SDK עם FB.login, שמאפשרת Pre-fill של פרטי העסק וקבלת WABA ID ו-Phone number ID ישר בדף (Session info). ה-code תקף לזמן קצר, לכן ההחלפה נעשית מיד בשרת עם App Secret. בחלון של Meta הלקוח יכול לבחור גם לחבר מספר שכבר עובד באפליקציה (Coexistence). ב-Tech Provider הלקוח מוסיף אמצעי תשלום משלו.
